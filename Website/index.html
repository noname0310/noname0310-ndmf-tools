Noname0310 NDMF Tools

NDMF tools for various avatar modifications.

Add to VCC

You can also add this repository URL in VCC under Settings > Packages > Add Repository:
https://noname0310.github.io/noname0310-ndmf-tools/index.json

Normal Field Offset

Move clothing vertices along a body mesh's surface normals to adjust the spacing between layered garments. Preview the result in the Scene view and apply it during the avatar build.

Usage and documentation

BlendShape Pose Override

Replace selected blendshapes with poses authored in animation clips, using the mesh's current customization as the basis. Includes optional VRC and MMD eye presets.

Usage and documentation

ALTO — Avatar Link-Time Optimizer

Static analysis-based optimization for VRChat avatars. Uses constant propagation, reachability and dependency analysis to optimize Animator logic, parameters, meshes, materials and physics.

Usage and documentation

Dependencies

Use a Unity 2022.3 avatar project with NDMF installed. BlendShape Pose Override and ALTO also require the VRChat Avatars SDK. BlendShape Pose Override additionally requires Modular Avatar.

Add the Modular Avatar repository to VCC so it can resolve the NDMF and Modular Avatar dependencies.

Additional packages for ALTO

Install these separately to use triangle reduction and material atlasing. Add each repository to VCC, then add the package to your project under Manage Project using a supported version below.

  • Meshia Mesh Simplification — required for ALTO Mesh Reduction. Supported versions: 3.2.0 or later, below 4.0.
    Add Meshia repository to VCC · Repository URL
  • TexTransTool — required for ALTO Material Atlas. Supported version: 1.0.2.
    Add TexTransTool repository to VCC · Repository URL
