Noname0310 NDMF Tools

NDMF tools for various avatar modifications.

Add to VCC

You can also add this repository URL in VCC under Settings > Packages > Add Repository:
https://noname0310.github.io/noname0310-ndmf-tools/index.json

Normal Field Offset

Move clothing vertices along a body mesh's surface normals to adjust the spacing between layered garments. Preview the result in the Scene view and apply it during the avatar build.

Usage and documentation

BlendShape Pose Override

Replace selected blendshapes with poses authored in animation clips, using the mesh's current customization as the basis. Includes optional VRC and MMD eye presets.

Usage and documentation

Dependencies

Use a Unity 2022.3 avatar project with NDMF installed. BlendShape Pose Override also requires Modular Avatar and the VRChat Avatars SDK.

Add the Modular Avatar repository to VCC so it can resolve the NDMF and Modular Avatar dependencies.
